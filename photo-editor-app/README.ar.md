# محرر الصور: دليل التشغيل (بالعربي)

كل الموديلات مجانية ومفتوحة المصدر وتشتغل على الموبايل بدون سيرفر وبدون أي تكلفة.

## 1) رفع المشروع من Termux إلى GitHub

```bash
pkg update && pkg install git
cd photo-editor-app            # فولدر المشروع بعد فك الضغط
git config --global user.name "اسمك"
git config --global user.email "ايميلك"
git init && git add . && git commit -m "photo editor"
git branch -M main
git remote add origin https://github.com/USERNAME/REPO.git
git push -u origin main
```

لما يطلب كلمة سر، استخدم **Personal Access Token** من GitHub (Settings > Developer settings > Tokens)، مش كلمة سر الحساب.
لو الريبو موجود فعلًا: فك الضغط فوق فولدر الريبو (اسمح بالاستبدال) ثم `git add . && git commit -m update && git push`.

## 2) بناء الـ APK

1. في GitHub: تبويب **Actions** ثم **Build APK** ثم **Run workflow**.
2. السكربت بينزّل لوحده موديل إزالة الخلفية (4.6 ميجا، وبيتأكد من MD5) وموديلات قراءة النص (حوالي 10 ميجا). مش لازم ترفعهم إنت.
3. لما يخلص، نزّل الـ artifact باسم `app-debug-apk` وثبّت `app-debug.apk`.

لو خطوة قراءة النص فشلت، التطبيق هيتبني عادي ولكن «قراءة النص» و«تعديل نص الصورة» و«تحديد كل النص» مش هتشتغل (والباقي شغال). راجع الروابط في `.github/workflows/android.yml`.

## 3) الموديلات: إيه اللي بيتنزّل ومتى

| الموديل | يعمل إيه | الحجم | أين |
|---|---|---|---|
| U2-Netp | إزالة الخلفية | 4.6 ميجا | داخل التطبيق (ينزل وقت البناء) |
| PaddleOCR (3 ملفات) | اكتشاف وقراءة النص عربي/إنجليزي | حوالي 10 ميجا | داخل التطبيق (ينزل وقت البناء) |
| **MI-GAN** | إزالة أي عنصر ومسح النص وملء مكانه | حوالي 80 ميجا | **مش داخل التطبيق**: بينزل مرة واحدة أول استخدام |

**MI-GAN:** أول مرة تضغط «إزالة» (أو «تنزيل الموديل الآن» في أداة إزالة عنصر) بينزل من huggingface ويتخزن على الموبايل، وبعدها بيشتغل **بدون إنترنت**. الأحسن تنزّله على واي فاي. لو التنزيل فشل (مفيش نت)، التطبيق بيستخدم الطريقة البسيطة القديمة ويقولك، ومش بيوقف.

لو عايز تضمّنه داخل التطبيق بدل التنزيل (APK أكبر): شغّل `bash scripts/get-models.sh --migan` ثم احذف سطر `public/models/migan_pipeline_v2.onnx` من `.gitignore` قبل الرفع (الملف حوالي 80 ميجا، تحت حد GitHub 100 ميجا).

## 4) طريقة استخدام الأدوات

- **إزالة الخلفية:** «إزالة الخلفية الآن» ثم عدّل الحواف بفرشاة مسح/استرجاع.
- **الخلفية:** شفاف أو لون أو صورة من المعرض (بعد إزالة الخلفية).
- **نص / الخطوط:** إضافة نص عربي أو إنجليزي، 27 خط، تحريك وحجم ولون.
- **تعديل نص الصورة (الجديد):**
  1. «اكتشاف النص» فتظهر مربعات حول السطور.
  2. اضغط على السطر المطلوب: يتقرأ النص تلقائيًا في خانتين (الأصلي والجديد).
  3. اكتب النص الجديد واضغط «استبدال النص».
  4. التطبيق بيمسح السطر القديم بموديل MI-GAN، ويختار أقرب خط من 27 خط، ويلتقط لون الحروف وحجمها من الصورة، ويضع النص الجديد في نفس المكان. بعدها عدّل أي شيء من أداة «نص».
  - «مسح السطر فقط» يمسح بدون كتابة بديل.
- **إزالة عنصر:** ارسم فوق الشيء ثم «إزالة». «تحديد كل النص تلقائيًا» يحدد كل الكلمات، وتقدر تعدّل التحديد بالفرشاة/الممحاة قبل المسح.
- **الخطوط:** حدّد منطقة نص ليظهر أقرب خط.
- **قص وتعديل (الجديد):**
  - الأشكال: مستطيل، حواف مستديرة، دائرة، قلب، نجمة، سداسي، مثلث، **رسم حر** (ترسم الشكل بإصبعك).
  - نسب: حر / 1:1 / 4:3 / 16:9 / 9:16. اسحب الزوايا لتغيير الحجم واسحب من الداخل للتحريك.
  - الأشكال غير المستطيلة تصير شفافية خارج الشكل (صدّر PNG أو WebP للحفاظ عليها).
  - **تغيير الحجم:** اكتب العرض أو الارتفاع (مع تثبيت النسبة). الحد الأقصى 4096 بكسل للضلع الأطول.
  - «تراجع عن القص/الحجم» يرجّع آخر عملية.
- **التصدير:** PNG / JPG / WebP، وبتتحدد تلقائيًا نفس صيغة الصورة الأصلية. القص يأخذ البكسلات من الصورة الأصلية كاملة الحجم فلا تقل الجودة.

## 5) حدود لازم تعرفها

- **الكود ما اتجرّبش على موبايل.** اختبرت حسابات القص والمسح وبروتوكول الموديل باختبارات آلية (39 اختبار)، وطلع بناء الويب سليم، لكن موديل MI-GAN نفسه ما اتشغّلش في بيئة التطوير (الموقع اللي بيستضيفه كان محجوب). أول تشغيل على جهازك هو الاختبار الحقيقي؛ لو الإزالة ملت بشكل غريب ابعتلي صورة الخطأ أو النتيجة.
- **السرعة:** الموديل بيشتغل على المعالج داخل الـ WebView بخيط واحد، فممكن ياخد من ثانيتين لعدة ثوانٍ حسب الموبايل. بياخد المنطقة حوالي العنصر فقط، مش الصورة كلها.
- **تعديل النص:** سطر سطر. الخط بيتم اختياره من الخطوط الموجودة في التطبيق (مش أي خط بالعالم). الخطوط الزخرفية جدًا أو النصوص بظل/حدود/تأثيرات هتطلع مختلفة. النص الجديد بيتوسّط مكان القديم.
- **قراءة العربي:** ترتيب الحروف بقاعدة بسيطة؛ الأسطر المختلطة عربي/إنجليزي ممكن تتلخبط، وتقدر تصحّح النص بإيدك قبل الاستبدال.
- **EXIF** (التاريخ والموقع وبيانات الكاميرا) مش بتتنقل للصورة المصدّرة. اتجاه الصورة بيتطبق صح.
- **الحجم الأقصى للتصدير:** 4096 بكسل للضلع الأطول.

## 6) لو حصلت مشكلة

| العَرَض | السبب والحل |
|---|---|
| فشل خطوة u2netp في Actions | الرابط أو الشبكة؛ أعد التشغيل، أو ارفع الملف في `public/models/u2netp.onnx` |
| «ملفات قراءة النص ناقصة» | خطوة OCR فشلت في Actions؛ شغّل `bash scripts/get-models.sh` وارفع الملفات الثلاثة في `public/models/` |
| «تعذّر تنزيل الموديل» | مفيش نت أو الرابط متغيّر؛ جرّب واي فاي، الروابط في `src/lib/migan.ts` |
| الإزالة بتطلع ضبابية | يعني استُخدمت الطريقة البسيطة (الموديل ما اشتغلش)؛ تأكد إن الموديل نزل |
| فشل البناء في خطوة Java | الكود الـ native ما اتترجمش قبل كده؛ ابعت الخطأ |
